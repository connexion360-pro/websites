100 % local · open source · sans Lotus Notes

Convertir un fichier .NSF sans l’envoyer sur Internet

Dépose ton archive Lotus Notes / HCL Notes. La conversion s’exécute dans ton navigateur grâce à WebAssembly. Ton fichier reste sur ton appareil.

1. Choisir le fichier

.nsf, .ntf ou .nsg · aucun compte requis

Traitement local
NSF

2. Choisir les exports

01

Privé par conception

Le fichier est lu en mémoire par le navigateur. Aucun upload, aucune API et aucun stockage serveur.

02

Export vérifiable

Le ZIP inclut un manifeste avec SHA-256 du fichier source, nombre de notes vérifiées et compteur des entrées non résolues.

03

Limites connues

Les NSF chiffrés ne sont pas déchiffrés. Certains très anciens variants de pièces jointes peuvent rester partiellement pris en charge.

Comment ça marche ?

Le cœur utilise sherlock-nsf-parser, un lecteur NSF Rust en lecture seule. Il parcourt les notes, résout leurs champs, reconstruit le texte riche et extrait les objets joints lorsque le format est pris en charge.
